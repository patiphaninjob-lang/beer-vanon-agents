สมุดบันทึกการเทรด v3.9.59💡 มีอะไรใหม่? (What's New)
⚠️ แคชค้าง? คลิกที่นี่เพื่อล้างแคช & รีโหลดใหม่
  • v3.9.59 (ล่าสุด): เพิ่มเส้นเชื่อมโยงการแสดงผลลัพธ์ระหว่างจุดแท่งเทียนที่เลือกกับรายการวิเคราะห์อารมณ์ความรู้สึก (Sentiment Analysis) ในแถบด้านข้าง พร้อมไฮไลต์อารมณ์ด้วยแสงสีตามประเภทอารมณ์ และรองรับการเคลื่อนย้ายหรือซ่อนเส้นและจุดเชื่อมโยงโดยอัตโนมัติเมื่อเลื่อนหน้าจอหรือสกรอลล์แถบด้านข้าง
  • v3.9.58: แก้ไขปัญหากราฟไม่ยอมล็อกอยู่กับที่ (Sticky CSS) บนอุปกรณ์มือถือและแท็บเล็ต โดยการเปลี่ยนค่าคุณสมบัติการแสดงผลของคอนเทนเนอร์หลัก (.shell) และ html/body จาก overflow: hidden และ overflow-x: hidden ให้เป็น overflow: visible ช่วยให้เบราว์เซอร์ประมวลผลคำสั่ง position: sticky ของทั้งแถบนำทางด้านบน (Topbar) และตัวกราฟราคาได้ถูกต้องแม่นยำ 100%
  • v3.9.57: ปรับปรุงระบบล็อกกราฟราคา (Sticky Chart) ในหน้า Journal ให้รองรับการล็อกปักหมุดบนทุกอุปกรณ์ รวมถึงหน้าจอมือถือและแท็บเล็ต โดยสแต็กกราฟอยู่ใต้แถบนำทาง (Topbar) ของมือถือที่มีการเรียงตัวแนวตั้งอย่างสมบูรณ์แบบ ช่วยให้สกรอลล์เขียนบันทึกอารมณ์ความรู้สึกลื่นไหลโดยไม่เสียทัศนวิสัยของกราฟราคา
  • v3.9.56: แก้ไขระบบล็อกกราฟราคาในหน้า Journal ให้ยกเลิกการล็อกปักหมุด (Sticky) เมื่อใช้งานบนอุปกรณ์มือถือ แท็บเล็ต หรือหน้าจอขนาดเล็ก โดยล็อกชาร์ตให้อยู่กับที่เฉพาะเมื่อดูบนเดสก์ท็อปขนาดใหญ่ (กว้างกว่า 1180px) และใช้เมาส์ควบคุมเท่านั้น เพื่อป้องกันไม่ให้กราฟขนาดใหญ่บดบังเนื้อหาฟอร์มเวลาเลื่อนบนหน้าจอเล็ก
  • v3.9.55: แก้ไขบั๊กสำคัญที่ทำให้กราฟของการ์ดที่มีโน้ตกลายเป็นกล่องดำว่างเปล่า โดยแก้ไขไวยากรณ์ในฟังก์ชันจัดกลุ่มโน้ต (groupNotesByDate) ที่มีตัวอักษร '\r\n' หลุดรอดเข้ามาทำให้โค้ดประกาศตัวแปร const d ถูกคอมเมนต์ทับและโยนข้อผิดพลาด ReferenceError: d is not defined จนตัววาดกราฟราคาพังเฉพาะการ์ดที่มีโน้ตบันทึก
  • v3.9.54: ปรับปรุงการโหลดกราฟให้เสถียร 100% โดยการแก้ปัญหา Race Condition เมื่อหน้าเว็บเริ่มวาดการ์ดแล้วขนาด canvas ยังเป็น 0px (ก่อน browser ประมวลผล layout) ระบบจะตรวจจับและหน่วงเวลาวาด (Deferred Retry Loop) ทุกๆ 50ms จนกว่าขนาดความกว้างจะพร้อมแสดงผลจริง และแก้ไขการตรวจสอบความเชื่อมโยง in DOM ด้วย canvas.isConnected ให้ถูกต้องตามมาตรฐาน
  • v3.9.53: แก้ไขบั๊กกราฟราคาโหลดไม่เสถียร (Unstable Chart Loading) บางการ์ดกราฟว่างเปล่าแบบสุ่ม โดยเพิ่มการตรวจสอบ DOM ก่อน render (DOM Detach Guard) เพื่อยกเลิกการวาดกราฟที่ถูก renderCards() เปลี่ยนไปก่อน fetch เสร็จ และเพิ่มระบบ Force-Load ทันทีสำหรับการ์ดที่อยู่ใน Viewport แทนการรอ IntersectionObserver
  • v3.9.52: แก้ไขบั๊กกราฟหน้าแรกไม่ซิงก์แท่งเทียนกับหน้า Journal เมื่อบันทึกโน้ตในวันที่ไม่ใช่วันเทรด (เช่น เสาร์-อาทิตย์) โดยแก้ไขฟังก์ชันจัดกลุ่มโน้ตตามวัน (groupNotesByDate) ให้อ่าน n.date ก่อน n.archive_date เหมือนหน้า Journal และเพิ่มระบบ Force-Redraw กราฟทุกการ์ดทันทีที่ Firestore อัปเดต Notes ใหม่
  • v3.9.51: เคลียร์และล้างข้อมูลจำลองการทดสอบระบบ (Mock Test Notes) ที่ตกค้างอยู่ในฐานข้อมูล Firestore และไฟล์ระบบเรียบร้อยแล้ว
  • v3.9.50: เพิ่มระบบล็อกกราฟราคาปักหมุดอยู่กับที่ (Sticky Chart on Scroll) ในหน้า Journal บนเดสก์ท็อป ช่วยให้เลื่อนเขียนโน้ตบันทึกและคลิกเปลี่ยนอารมณ์ข้างล่างได้โดยยังเห็นความเคลื่อนไหวของกราฟราคาประกอบการวิเคราะห์ตลอดเวลา
  • v3.9.49: แยกตรรกะ "ฤดูตลาดใหญ่ล่าสุด" (Market Season) ด้านบนให้เป็นอิสระ โดยอ่าน/เขียนและสลับเฉพาะผ่านปุ่มคลิกหัวข้อโดยตรงเท่านั้น ไม่ถูกเปลี่ยนค่าตามการเขียนโน้ตในดัชนี Index อื่นๆ, และแก้ไขบั๊กกราฟหน้าแรกไม่ซิงก์แท่งเทียนกับหน้า Journal ในวันหยุดเสาร์-อาทิตย์
  • v3.9.48: แก้ไขบั๊กปุ่มลูกศรเลื่อน ‹ › บน Tooltip กดไม่ได้เมื่ออยู่ในโหมดกราฟขยายเต็มจอ (Fullscreen) บนหน้าแรก โดยอัปเดต noteIndices และ currentPos ให้สอดคล้องกับ canvas ตัวใหม่ทุกครั้งที่ทำการ reposition เส้นเชื่อมและกล่อง Tooltip
  • v3.9.47: ฮอตฟิกซ์ (Hotfix) แก้ไขบั๊กแครชหน้าจอหลัก notes is not iterable โดยเพิ่มการตรวจสอบชนิดตัวแปร Array.isArray(notes) ก่อนเริ่มกระบวนการลูปอ่านข้อมูลโน้ตเพื่อความปลอดภัย 100%
  • v3.9.46: อัปเกรดระบบค้นหาไฟล์และหน้าแรกให้ซัพพอร์ตวันหยุดเสาร์-อาทิตย์อย่างสมบูรณ์แบบ โดยมี Fallback ดึงการบ้านล่าสุดที่ใกล้เคียง และประมวลผลวันหยุดที่มีโน้ตร่วมเข้าไปในตัวเลือกวันตั้งแต่เริ่มโหลด
  • v3.9.45: อัปเกรดระบบชาร์ตหน้าแรกให้สร้างแท่งเทียนจำลองวันหยุดเสาร์-อาทิตย์ (Placeholder candles) สำหรับวันที่มีบันทึกโน้ต เพื่อให้ชาร์ต NVDA หน้าแรกและหน้า Journal แสดงป้าย 💡 และเชื่อมโยงข้อมูลป๊อปอัปสอดประสานกัน 100%
  • v3.9.44: แก้ไขระบบบันทึกโน้ตวันหยุดให้บันทึกแยกชิ้นกันอย่างถูกต้องตามวันที่เขียนจริง (n.date) ป้องกันการบันทึกทับ (Overwrite) โน้ตตัวเก่า พร้อมทั้งปลดล็อกให้หน้าแรกแสดงวันที่วันหยุดเสาร์-อาทิตย์บนปฏิทินหากมีบันทึกของวันนั้น ช่วยให้สลับดูสรุปโน้ตการบ้านรายวันและวันหยุดได้อย่างสอดประสานกัน 100%
  • v3.9.41: เพิ่มการแสดงผลสถานะ "๖ ฤดูของตลาด (Market Season)" บนส่วนหัวแบนเนอร์ของหน้าแรก โดยคำนวณจากโน้ตบันทึกดัชนีตลาดหลักล่าสุด มีระบบเปลี่ยนเฉดสี Glassmorphism ตามสภาวะตลาดจริง และทางลัดการคลิกเพื่อเข้าไปประเมินฤดูกาลของตลาดใหญ่ได้ทันที
  • v3.9.40: อัปเกรดมุมทบทวนฝั่งขวาเป็น "สถิติจิตวิทยาการเทรด" (Trader Sentiment Stats) โดยคำนวณจากบันทึกในอดีตของหุ้นตัวนั้นๆ ดึงอัตราการชนะ (Win Rate) และสัดส่วน ชนะ/แพ้ (Wins/Losses) แยกประเมินความเชื่อมโยงตามความรู้สึกของคุณ (Sentiment vs Win-Loss Ratio) แสดงผลเป็นแถบพลังพลังสีเขียวแดงแบบเรียลไทม์สะท้อนผลลัพธ์จิตวิทยาเทรดเดอร์ได้ชัดเจนขึ้น
  • v3.9.39: เพิ่มระบบสลับโหมดป้อนข้อมูลเป้ากำไร (Target) และจุดตัดขาดทุน (Stop Loss) แบบสไลด์ปรับแต่งได้ละเอียด ทั้งโหมดป้อนราคาแน่นอน (Price) หรือป้อนระดับเปอร์เซ็นต์ (% กำไร / % ขาดทุน) แบบสไตล์ TradingView โดยมีการคำนวณและแสดงผลแปลงค่าคู่ขนานอีกโหมดข้างใต้อินพุตแบบเรียลไทม์ และแปลงค่าคงเดิมอัตโนมัติเมื่อกดสลับปุ่มโหมดไปมา
  • v3.9.38: เพิ่มระบบดึงราคาซื้อล่าสุดแบบอัตโนมัติ (Auto-Populate Entry Price) ในหน้า Journal โดยจะกรอกราคาปิดของวันเทรดจริงหรือราคาปิดล่าสุดของหุ้นตัวนั้นให้อัตโนมัติเมื่อเปิดหน้ากระดาษโน้ตใหม่ พร้อมแสดงปุ่มทางลัดแนะนำดึงราคาปิด 🎯 ข้างป้ายช่องกรอกข้อมูลเพื่อความสะดวกในการคำนวณ RRR รวดเร็วโดยไม่ต้องย้อนไปดูประวัติราคาเอง
  • v3.9.37: อัปเกรดระบบล็อคตำแหน่งป๊อปอัปบนหน้าแรก (Homepage Stable Tooltip Lock) รองรับการแสดงผลกล่องข้อมูลค้างเสถียรเมื่อเปลี่ยนช่วงเวลากราฟ (1M, 6M, 1Y...) หรือเมื่อเปิดขยายกราฟเป็นเต็มจอ ⛶ และเกาะตำแหน่งกลับมายังกราฟขนาดเล็กของการ์ดเดิมเมื่อปิดตัวเต็มจอ พร้อมบล็อกไม่ให้การคลิกควบคุมกราฟแอบสั่งปิด Tooltip โดยไม่ตั้งใจ
  • v3.9.36: แก้ไขบั๊กกล่องข้อมูลเด้งแวบแล้วหายไป (Tooltip Flicker & Disappear Race Condition) ในหน้า Journal ปรับปรุงโดยการย้ายฟังก์ชันล้าง Tooltip และเคลียร์แคชไปทำงานเฉพาะจังหวะที่ผู้ใช้งานเปลี่ยนคลิกหุ้นตัวใหม่จริงๆ เท่านั้น ป้องกันไม่ให้การโหลด Archive แบบ Async ย้อนกลับมาล้างสถานะป๊อปอัปของวันเดิมให้สั่นหรือหายไปขณะวาดหน้าจอใหม่
